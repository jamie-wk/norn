# {{name}}

A [Norn](https://jamie-wk.github.io/norn/) project: durable workflows on Temporal, in typed TypeScript.

```sh
pnpm dev        # Temporal (if it isn't running), norn gen --watch and the worker
pnpm order      # in another terminal: start an order, then open the link it prints
pnpm test       # the workflow's tests, on Temporal's time-skipping server
pnpm typecheck
```

`pnpm order cancel <id>` cancels an order within 5 minutes (it is refunded); `pnpm order status <id>` asks it for its status.

## What's where

| Path | What |
| --- | --- |
| `src/workflows/order.workflow.ts` | The workflow: charge, wait for a cancellation, maybe refund. Deterministic, replayed by Temporal. |
| `src/activities/payment.activities.ts` | Activities: the steps that do I/O. Temporal retries them. |
| `src/services/payment-gateway.ts` | A service injected into the activities, behind a token. |
| `src/worker.ts` | The worker process. |
| `src/order.ts` | A client script that starts, signals and queries orders. |
| `test/order.workflow.test.ts` | Tests with mocked activities. |
| `.norn/` | Generated by `norn gen` from your decorators. Commit it. |
