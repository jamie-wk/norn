# @norn-ts/workflow

Write [Temporal](https://temporal.io) workflows as decorated TypeScript classes with [Norn](https://jamie-wk.github.io/norn/). `run()` is the workflow, decorated methods are signal, query and update handlers, and activities and child workflows are called through typed proxies.

## Install

```sh
pnpm add @norn-ts/workflow @temporalio/workflow @temporalio/common
```

Requires Node 22.18+ and TC39 standard decorators (do not enable `experimentalDecorators`).

## Example

```ts
import { condition } from '@temporalio/workflow';
import { Query, Signal, Workflow, useActivities } from '@norn-ts/workflow';
// generated by norn gen, workflow-safe
import { PaymentActivities } from '../../.norn/activities';

@Workflow({ taskQueue: 'orders', id: 'order-{orderId}' })
export class OrderWorkflow {
  private readonly payments = useActivities(PaymentActivities);
  private canceled = false;

  @Signal() cancel() {
    this.canceled = true;
  }

  @Query() status() {
    return this.canceled ? 'canceled' : 'open';
  }

  async run(input: { orderId: string; cents: number }) {
    if (await condition(() => this.canceled, '1 hour')) return 'canceled';
    await this.payments.charge(input.orderId, input.cents);
    return 'paid';
  }
}
```

Full API: [reference](https://jamie-wk.github.io/norn/reference/workflow/) · [Norn docs](https://jamie-wk.github.io/norn/)
