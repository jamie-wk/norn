# @norn-ts/worker

`createWorker()` for [Norn](https://jamie-wk.github.io/norn/): turns the registry generated by `norn gen` into a production worker process, with one Temporal worker per task queue, dependency-injected activities, health checks, graceful shutdown, worker versioning and Prometheus metrics.

## Install

```sh
pnpm add @norn-ts/worker @temporalio/worker @temporalio/workflow @temporalio/activity @temporalio/common @temporalio/client
```

Requires Node 22.18+ on a glibc-based system (not Alpine).

```ts
// src/worker.ts
import { createWorker, installRuntime } from '@norn-ts/worker';
import { registry } from '../.norn/registry';

installRuntime();
const worker = await createWorker({ registry });
await worker.run();
```

Full API: [reference](https://jamie-wk.github.io/norn/reference/worker/) · [Norn docs](https://jamie-wk.github.io/norn/)
