# Changelog & upgrading

Release notes for every version are on [GitHub Releases](https://github.com/jamie-wk/norn/releases). Each package also keeps its own `CHANGELOG.md` (for example [`packages/core/CHANGELOG.md`](https://github.com/jamie-wk/norn/blob/main/packages/core/CHANGELOG.md)), generated from [changesets](/contributing#changesets), which lists the changes and any upgrade steps.
