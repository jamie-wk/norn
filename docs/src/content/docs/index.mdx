## Running in a minute

All you need is Node.js 22.18 or later. `pnpm dev` downloads and starts a local Temporal server for you.

```sh
pnpm create @norn-ts my-app
cd my-app
pnpm dev
```

Then, in a second terminal, run `pnpm order` and open the link it prints. You'll see an order workflow running in the Temporal Web UI.

## Three files

A workflow charges a card, then waits five minutes for a cancellation. If the worker crashes during the wait, Temporal replays the history on another worker and the timer carries on.

<Tabs>
<TabItem label="Workflow">

```ts
// src/workflows/order.workflow.ts
import { condition } from '@temporalio/workflow';
import { Query, Signal, Workflow, useActivities } from '@norn-ts/norn/workflow';
import type { PaymentActivities } from '../activities/payment.activities';

@Workflow({ taskQueue: 'orders', id: 'order-{orderId}' })
export class OrderWorkflow {
  private status: 'pending' | 'paid' | 'refunded' = 'pending';
  private canceled = false;
  private readonly payments = useActivities<PaymentActivities>('payments', {
    timeout: '30s',
    retries: 3,
    nonRetryable: ['CardDeclinedError'],
  });

  @Signal() cancel(_reason: string) {
    this.canceled = true;
  }

  @Query() getStatus() {
    return this.status;
  }

  async run(input: { orderId: string; cents: number }) {
    const charge = await this.payments.charge(input.orderId, input.cents);
    this.status = 'paid';
    if (await condition(() => this.canceled, '5 minutes')) {
      await this.payments.refund(charge.id);
      this.status = 'refunded';
    }
    return this.status;
  }
}
```

<TabItem label="Activities">

```ts
// src/activities/payment.activities.ts: a plain class, where the I/O happens
export class PaymentActivities {
  constructor(private readonly gateway: PaymentGateway) {}

  async charge(orderId: string, cents: number) {
    return this.gateway.charge({ orderId, cents, idempotencyKey: `charge-${orderId}` });
  }

  async refund(chargeId: string) {
    return this.gateway.refund(chargeId);
  }
}
```

## What you get

<CardGrid>
  <Card title="Just classes" icon="approve-check">
    Decorated workflow classes, plain activity classes, and a worker you hand both to. Nothing is generated, and
    there's nothing to keep in sync.
  </Card>
  <Card title="Typed from the class" icon="puzzle">
    Inputs, results, handler arguments and activity signatures come straight from your classes, in workflows and in
    the client.
  </Card>
  <Card title="Sandbox-safe" icon="warning">
    Workflows import activity classes with `import type`, so activity code never reaches the workflow sandbox.
  </Card>
  <Card title="Tests that skip time" icon="rocket">
    `useTestEnv()` runs your workflows on Temporal's time-skipping server with fake activities, so a five-day timer
    takes milliseconds.
  </Card>
</CardGrid>
